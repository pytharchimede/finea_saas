# Guide gestionnaire

## Objectif de l Espace employe

L Espace employe est la porte d entree individuelle de chaque collaborateur dans l application.

Il permet de regrouper, dans une interface simple :

- le pointage ;
- les demandes RH et FEB ;
- le suivi des demandes ;
- les explications attendues ;
- l acces au formulaire de fiche de decaissement ;
- certains raccourcis utiles au quotidien.

## Pourquoi ce module est important

Pour un gestionnaire RH ou un responsable support, cet espace est important car il conditionne l autonomie de l employe.

Quand il est correctement utilise, l employe peut :

- soumettre ses demandes au bon circuit ;
- suivre leur statut ;
- justifier des absences ;
- reduire les sollicitations hors systeme.

## Ce qu un gestionnaire doit surveiller

- que l employe soit bien rattache a son profil RH ;
- que les demandes soient correctement orientees vers RH ou Finance ;
- que les absences et explications remontent correctement ;
- que l experience soit assez claire pour limiter les erreurs de saisie.

## Tableau de bord employe

Le dashboard affiche notamment :

- le profil RH rattache ;
- les alertes d absences a justifier ;
- le nombre de demandes en attente ;
- l acces rapide aux actions frequentes.

## Demandes de l employe

Depuis les Actes legaux, l employe peut initier des demandes comme :

- permission d absence ;
- pret ;
- avance sur salaire ;
- heures supplementaires ;
- FEB.

Chaque demande suit ensuite un circuit de validation RH ou Finance selon son type.

## Role du gestionnaire

Le gestionnaire n utilise pas cet espace comme l employe, mais il doit en connaitre le fonctionnement pour :

- assister un collaborateur ;
- verifier qu une demande a ete faite au bon endroit ;
- comprendre l origine d un dossier ;
- corriger un probleme de liaison compte / personnel.

## Bonnes pratiques

- verifier l email professionnel rattache au collaborateur ;
- verifier la liaison avec la fiche personnel ;
- former les employes a passer par cet espace plutot que par des messages disperses ;
- controler les demandes en attente trop anciennes.

## Resultat attendu

L Espace employe doit devenir le canal standard des demandes individuelles et du suivi personnel dans l ERP.
