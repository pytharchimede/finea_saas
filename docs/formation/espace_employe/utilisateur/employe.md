# Guide employe

## A quoi sert l Espace employe

![Vue Employe](captures/employe.png "Capture de Employe")


L Espace employe rassemble vos actions personnelles dans l application.

Vous pouvez y retrouver :

- votre pointage ;
- vos demandes RH et FEB ;
- le suivi de vos demandes ;
- vos explications ;
- certains acces rapides utiles.

## Ce que vous pouvez faire

Depuis le dashboard, vous pouvez :

- aller vers le pointage ;
- creer une demande ;
- suivre vos demandes ;
- consulter vos alertes ;
- ouvrir le formulaire de fiche de decaissement si vous y avez recours.

## Faire une demande

Dans Actes legaux, choisissez le type de demande adapte :

- permission d absence ;
- pret ;
- avance sur salaire ;
- heures supplementaires ;
- FEB.

Choisissez toujours le bon type pour que la demande parte au bon service.

## Suivre vos demandes

Le suivi de vos demandes permet de voir si une demande est :

- en attente ;
- approuvee ;
- refusee ;
- finalisee selon le circuit.

## Pointage

Votre pointage doit rester coherent avec votre activite reelle. Si vous constatez une anomalie, remontez-la rapidement au service concerne.

## Alertes et explications

Si l application vous signale des absences a justifier ou des explications attendues, traitez-les le plus vite possible pour eviter les blocages ou incomprehensions.

## Bons reflexes

- utiliser cet espace plutot que des demandes informelles ;
- verifier l avancement de vos demandes ;
- signaler une erreur de profil si votre espace semble incomplet ;
- ne pas dupliquer plusieurs fois la meme demande.

## En resume

L Espace employe est votre tableau de bord personnel. Il vous aide a faire vos demandes proprement et a suivre leur traitement.
