# Guide gestionnaire

## Objectif du module Documentation & Archives

Ce module sert à stocker, classer, retrouver, partager et archiver les documents de référence de l entreprise.

Il ne remplace pas les échanges rapides. Son rôle est de conserver les documents importants dans une structure durable.

## Ce que vous pouvez faire

- créer des dossiers et sous-dossiers ;
- déposer des documents ;
- les classer par chantier, direction, service ou référentiel ;
- rechercher un document ;
- partager un document ou un dossier ;
- archiver un document ;
- consulter l historique documentaire.

## Espaces documentaires

Le module distingue plusieurs espaces, par exemple :

- chantiers ;
- directions ;
- services ;
- référentiel général ;
- archives.

Cette organisation évite de mélanger les usages et aide à retrouver les bons fichiers.

## Utilisation recommandée

Pour un gestionnaire, le bon usage consiste à :

1. créer ou choisir le bon dossier ;
2. déposer le document dans le bon espace ;
3. renseigner le titre et le contexte ;
4. appliquer si besoin une restriction d audience ;
5. utiliser l archivage quand le document ne doit plus être modifié librement.

## Partage

Le module permet de partager des documents ou dossiers avec des droits précis.

Exemples :

- lecture seule ;
- téléchargement autorisé ;
- édition autorisée ;
- re-partage autorisé.

## Ce qu il faut éviter

- déposer un document au mauvais endroit ;
- utiliser le module comme un simple espace temporaire ;
- multiplier les doublons ;
- partager trop largement un document sensible ;
- conserver des documents officiels uniquement dans les pièces jointes de communication.

## Résultat attendu

Le module doit devenir la source documentaire fiable de l application, là où l on vient chercher le bon document de référence.
