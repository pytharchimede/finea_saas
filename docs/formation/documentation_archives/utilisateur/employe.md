# Guide utilisateur

## A quoi sert ce module

Documentation & Archives sert à retrouver les documents officiels ou utiles dans l application.

Vous pouvez y consulter des documents classés par contexte, au lieu de chercher dans des messages, téléchargements dispersés ou anciens échanges.

## Ce que vous pouvez faire

Selon vos droits, vous pouvez :

- ouvrir un dossier ;
- consulter un document ;
- télécharger un document ;
- déposer un document ;
- partager un lien ;
- voir des archives.

## Comment bien l utiliser

- cherchez d abord le bon espace ;
- vérifiez le titre du document ;
- évitez de redéposer un fichier déjà existant ;
- utilisez le bon dossier si vous devez importer un document.

## Différence avec Mes tâches

Mes tâches sert au suivi d actions et aux échanges liés à une tâche.

Documentation & Archives sert à conserver le document de référence à long terme.

## En résumé

Quand vous avez besoin d un document fiable et bien classé, c est ici qu il faut venir le chercher.
