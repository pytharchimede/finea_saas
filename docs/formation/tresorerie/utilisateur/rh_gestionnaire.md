# Guide gestionnaire

## Objectif de l Espace tresorerie

L Espace tresorerie sert au suivi et au traitement des fiches financieres a un stade avance du workflow.

Il permet notamment de :

- filtrer les fiches ;
- rechercher rapidement une demande ;
- separer les situations immediates, reportees, partielles ou deja decaissees ;
- analyser les montants et l etat d avancement.

## A quoi sert ce module pour un gestionnaire

Pour un responsable transverse, cet ecran aide a comprendre :

- quelles fiches arrivent en tresorerie ;
- quelles demandes sont encore en attente ;
- quels montants doivent etre suivis ;
- quelles situations meritent arbitrage ou relance.

## Filtres disponibles

L ecran permet de filtrer par exemple par :

- numero de fiche ;
- beneficiaire ;
- designation ;
- precision ;
- chantier ;
- entreprise ;
- montants ;
- dates ;
- affectation ;
- statut.

## Lecture conseillee

Utilisez ce module comme un ecran de pilotage des fiches au stade tresorerie, pas comme un simple tableau de consultation.

## Bonnes pratiques

- filtrer avant d analyser ;
- verifier le statut reel d une fiche ;
- utiliser le numero de fiche pour les investigations precises ;
- distinguer les decaissees des reportees et des partiels.

## Resultat attendu

Le module doit aider la tresorerie et les responsables a garder une vue claire et exploitable des paiements et dossiers a traiter.
