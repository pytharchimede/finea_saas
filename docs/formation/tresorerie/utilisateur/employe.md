# Guide utilisateur

## A quoi sert cet espace

L Espace tresorerie est reserve aux profils autorises. Il sert a consulter et suivre les fiches en phase comptable ou de decaissement avance.

## Ce que vous pouvez y faire

- rechercher une fiche ;
- filtrer les demandes ;
- identifier les fiches decaissees ;
- reperer les fiches reportees ou partiellement traitees ;
- ouvrir plus facilement une investigation financiere.

## Comment bien lire l ecran

Commencez toujours par un filtre simple :

- numero de fiche ;
- beneficiaire ;
- chantier ;
- statut.

Ensuite seulement, elargissez si besoin.

## Point important

Cet espace n est pas la meme chose que le Point financier. Il est plus oriente traitement / suivi tresorerie sur les fiches, alors que le Point financier donne une vue plus analytique et consolidée.

## En resume

Cet ecran sert surtout a operer et rechercher dans le flux tresorerie des fiches de decaissement.
