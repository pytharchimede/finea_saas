# Guide employe

## Pourquoi ce module existe

Le module RH regroupe les informations et processus administratifs liés à la vie du collaborateur dans l application.

Selon vos droits, vous pouvez surtout être concerné par :

- votre dossier ;
- vos missions ;
- votre pointage ;
- certaines demandes ou validations ;
- vos documents RH.

## Ce que vous pouvez consulter

Suivant votre profil, vous pouvez voir :

- des informations sur votre fiche ;
- des ordres de mission vous concernant ;
- des éléments de pointage ;
- des états liés à vos demandes.

## Votre dossier

Votre dossier personnel sert à conserver vos informations administratives et professionnelles.

Si une information est erronée, il faut la signaler au service RH pour correction.

Exemples :

- nom mal orthographié ;
- téléphone incorrect ;
- statut contractuel erroné ;
- date importante incohérente.

## Missions

Si vous êtes envoyé en mission, le module peut contenir :

- la destination ;
- l objet de la mission ;
- les dates prévues ;
- l état d avancement ;
- certaines dépenses prévues.

Pensez à consulter ces informations avant un déplacement.

## Pointage

Le pointage sert à suivre vos présences et votre temps de travail.

Selon l organisation interne, certaines saisies sont faites par la RH ou par le responsable. Si vous remarquez une anomalie, il faut la remonter rapidement.

## Demandes et validations

Certaines demandes peuvent suivre un circuit RH dans l application. Si vous êtes sollicité pour fournir une explication, un document ou une validation, faites-le dans le bon espace et le plus tôt possible.

## Bonnes habitudes

- vérifier vos informations quand elles vous sont présentées ;
- signaler rapidement toute erreur ;
- consulter les missions avant départ ;
- ne pas attendre la fin du mois pour signaler un problème de pointage.

## En résumé

Pour un employé, le module RH est avant tout un point de référence administratif. Il aide à garder des informations justes et à mieux suivre les processus liés à la vie professionnelle.
