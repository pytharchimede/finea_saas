# Guide RH gestionnaire

## Objectif du module RH

Le module RH centralise la gestion du personnel dans l application.

Il permet a un responsable RH de :

- consulter l effectif ;
- créer et mettre à jour les dossiers du personnel ;
- gérer les sorties ;
- suivre les ordres de mission ;
- saisir le pointage ;
- préparer la paie ;
- valider certaines demandes ;
- maintenir les paramètres RH.

## Point d entrée

L entree principale est le Tableau de bord RH.

Depuis ce tableau de bord, vous accédez rapidement aux principales zones de travail :

- liste du personnel ;
- intégration d un collaborateur ;
- ordres de mission ;
- pointage journalier ;
- paie ;
- paramétrage RH.

## Gérer le personnel

Le cycle de base est simple :

1. créer le dossier d un collaborateur ;
2. compléter ses informations ;
3. le rattacher à un service, une fonction et un site ;
4. mettre à jour sa situation au fil du temps ;
5. enregistrer sa sortie si la collaboration prend fin.

La qualité du module dépend fortement de la qualité des données saisies au départ.

## Intégrer un collaborateur

Lors de l intégration, renseignez autant que possible :

- identité professionnelle ;
- coordonnées ;
- statut contractuel ;
- informations familiales utiles ;
- numéros administratifs ;
- contact d urgence.

Bonnes pratiques :

- vérifier le nom complet ;
- vérifier le service et la fonction ;
- vérifier les dates importantes ;
- éviter les dossiers incomplets si une donnée est disponible.

## Dossier personnel

Le dossier personnel est la fiche de référence du collaborateur.

Il sert à :

- consulter les données RH ;
- corriger une erreur ;
- compléter une information manquante ;
- accéder à des actions rapides comme la sortie, la paie ou le pointage.

## Sortie de personnel

Quand un collaborateur quitte l entreprise :

1. ouvrez sa fiche ;
2. choisissez le motif de sortie ;
3. renseignez la date de fin ;
4. confirmez la sortie.

Le collaborateur passe alors hors du périmètre des actifs, tout en restant consultable dans les vues adaptées.

## Ordres de mission

Le module RH permet de préparer et suivre les ordres de mission.

Utilisez cette partie pour :

- définir la destination et l objet ;
- prévoir les dates ;
- suivre l état de la mission ;
- gérer les dépenses prévues ;
- garder un historique de progression.

## Pointage

Le pointage journalier sert a renseigner la présence et le temps travaillé.

Vous pouvez y saisir :

- statut du jour ;
- jours travaillés ;
- heures supplémentaires ;
- heures d arrivée et de départ ;
- note libre.

Le pointage doit être tenu régulièrement pour fiabiliser la paie.

## Paie

Le module RH prépare aussi la paie à partir des données enregistrées.

Pour un usage propre :

- vérifier les pointages avant calcul ;
- vérifier les règles contractuelles ;
- vérifier les absences et missions ;
- corriger les anomalies avant validation finale.

Un guide dedie est disponible dans ce module de formation : **Parametrage moteur paie**.

Il explique, pas a pas, comment :

- utiliser l assistant de paie ;
- regler les coefficients par type de contrat ;
- comprendre le moteur de paie CI ;
- creer une nouvelle version de regles ;
- modifier les rubriques, tranches, cotisations et plafonds ;
- cloturer une periode ;
- verifier l audit.

## Paramétrage RH

Le paramétrage RH sert à maintenir les référentiels du module, par exemple :

- services ;
- fonctions ;
- statuts ;
- sites ;
- hiérarchie ;
- horaires de planification ;
- paramètres de contrat ou de paie.

Cette partie doit être réservée aux profils capables de maintenir les règles métier RH.

## Ce qu il faut éviter

- créer un dossier incomplet alors que les informations sont disponibles ;
- modifier une fiche sans vérifier la cohérence globale ;
- faire le pointage en retard sur une longue période ;
- gérer les sorties en dehors du module ;
- utiliser plusieurs sources différentes pour la même information RH.

## Résultat attendu

Si le module RH est bien utilisé, il devient la source fiable pour la gestion des collaborateurs, leur organisation administrative et leur suivi opérationnel.
