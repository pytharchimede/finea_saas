# Guide utilisateur

## A quoi sert ce module

Le module Fournisseurs permet de consulter et gerer les fiches fournisseurs autorisees dans l application.

## Ce que vous pouvez y faire

- consulter le referentiel ;
- creer un fournisseur selon vos droits ;
- modifier une fiche existante ;
- verifier si un fournisseur est actif ;
- verifier si les informations utiles sont presentes.

## Avant de creer une nouvelle fiche

Toujours verifier qu un fournisseur n existe pas deja. Cela evite les doublons et les problemes dans les factures.

## Informations importantes

Les champs utiles a surveiller sont :

- raison sociale ;
- code fournisseur ;
- NCC ou RNE ;
- email ;
- telephone ;
- adresse ;
- statut actif.

## En resume

Ce module sert a garder un referentiel fournisseur propre, sans doublons et suffisamment complet pour les usages de facturation.
