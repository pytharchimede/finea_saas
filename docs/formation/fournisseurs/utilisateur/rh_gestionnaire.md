# Guide gestionnaire

## Objectif du module Fournisseurs

Le module Fournisseurs sert a maintenir le referentiel des partenaires fournisseurs utilises par l application, en particulier pour les besoins de facturation et de conformite FNE.

## Ce que permet le module

- creer un fournisseur ;
- completer sa fiche ;
- gerer son statut actif ou inactif ;
- renseigner ses identifiants comme NCC ou RNE ;
- garder des coordonnees propres ;
- preparer les donnees necessaires aux factures.

## Dashboard fournisseurs

Le tableau de bord donne une vue rapide sur :

- le nombre de fournisseurs ;
- les actifs et inactifs ;
- la qualite des donnees ;
- les identifiants manquants ;
- les derniers fournisseurs crees.

## Pourquoi la qualite des donnees est importante

Une fiche fournisseur incomplete ou mal renseignee peut bloquer ou degradar les traitements de facturation.

Il faut donc surveiller :

- NCC manquant ;
- RNE manquant ;
- contact absent ;
- incoherence du type fournisseur.

## Creation d un fournisseur

Lors de la creation, renseignez au minimum :

- raison sociale ;
- type d identifiant utile ;
- email ou telephone si disponibles ;
- informations d adresse si connues.

## Resultat attendu

Le module Fournisseurs doit servir de socle propre et fiable pour la suite des traitements de facturation.
