# Guide gestionnaire

## Objectif du module Emails

Le module Emails permet de consulter la boite professionnelle depuis l ERP, sans quitter l environnement applicatif.

## Ce que permet le module

- ouvrir la boite de reception ;
- filtrer les messages ;
- consulter les non lus ;
- parcourir les dossiers IMAP ;
- ouvrir un message ;
- rediger un nouvel email ;
- telecharger une piece jointe.

## Interet pour un gestionnaire

Pour un gestionnaire, ce module sert a centraliser les echanges utiles au travail quotidien, sans multiplier les outils ouverts en parallele.

## Fonctionnement general

Le module utilise l email professionnel du compte connecte. L utilisateur renseigne son mot de passe de messagerie pour la session afin d ouvrir la boite.

## Points de vigilance

- verifier que l email professionnel est bien renseigne ;
- comprendre que le mot de passe de messagerie est distinct du mot de passe ERP ;
- deconnecter la boite mail si besoin en fin d usage ;
- eviter de traiter ce module comme un historique systeme, car il s agit d abord d une consultation de boite personnelle.

## Resultat attendu

Le module Emails doit offrir un acces simple et pratique a la messagerie professionnelle depuis l ERP.
