# Guide utilisateur

## A quoi sert ce module

Le module Emails vous permet de consulter votre boite professionnelle dans l ERP.

## Comment l utiliser

1. ouvrez le module ;
2. verifiez votre adresse professionnelle affichee ;
3. saisissez le mot de passe de votre email si demande ;
4. consultez vos messages ;
5. ouvrez un email ou redigez-en un nouveau.

## Fonctions utiles

- voir tous les emails ;
- voir les non lus ;
- parcourir les dossiers ;
- actualiser ;
- ouvrir une piece jointe ;
- rediger un nouveau message.

## Si la boite ne s ouvre pas

Verifier :

- que votre email professionnel existe dans votre compte ;
- que vous avez bien saisi le mot de passe mail ;
- que vous n utilisez pas le mauvais mot de passe.

## En resume

Ce module sert a acceder a votre messagerie pro directement depuis l ERP.
