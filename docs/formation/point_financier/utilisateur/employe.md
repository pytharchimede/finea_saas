# Guide utilisateur

## A quoi sert cet écran

Le Point financier sert à consulter l état des fiches de décaissement dans un cadre global. Ce n est pas l écran de saisie initiale d une fiche, mais plutôt un écran de suivi et d analyse.

## Ce que vous pouvez comprendre avec cet écran

Vous pouvez y voir :

- si des demandes existent ;
- à quel stade elles se trouvent ;
- quels montants sont concernés ;
- quels bénéficiaires ou chantiers sont impactés.

## Utiliser les filtres

Avant de lire les résultats, appliquez les bons filtres :

- un état ;
- un chantier ;
- un bénéficiaire ;
- un déboursé ;
- une période.

Le bandeau de synthèse dans la zone de filtres vous aide ensuite à vérifier si vous regardez bien le bon périmètre.

## Lire la liste

La liste détaillée permet d identifier :

- le numéro de fiche ;
- le bénéficiaire ;
- le montant ;
- la référence utile ;
- le statut réel ou l étape de traitement.

## Bon réflexe

Toujours vérifier le filtre Etat de la demande avant d interpréter les chiffres. Un même montant peut être visible différemment selon que vous observez les demandes créées, en attente, refusées ou décaissées.

## En résumé

Le Point financier est un écran de lecture et de pilotage. Il sert à comprendre le parcours des fiches et non à remplacer les écrans métiers de saisie ou de validation.
