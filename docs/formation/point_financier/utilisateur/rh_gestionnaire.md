# Guide gestionnaire

## A quoi sert le Point financier

Le Point financier est l écran de pilotage des fiches de décaissement. Il permet de suivre le volume, les montants et l état des demandes dans le circuit financier.

Même si ce module concerne surtout la finance, un gestionnaire transverse peut s en servir pour comprendre où se situent les demandes et quels montants sont engagés ou bloqués.

## Ce que vous pouvez voir

Le module affiche notamment :

- les montants demandés ;
- les montants décaissés ;
- les montants en attente ;
- les refus ;
- les regroupements par bénéficiaire, chantier ou catégorie ;
- la liste détaillée des fiches.

## Filtres principaux

Les filtres servent à réduire l affichage selon :

- l état de la demande ;
- le bénéficiaire ;
- le chantier ;
- le déboursé ;
- une date exacte ou une période.

L écran contient aussi un récapitulatif visible dans la zone de filtres après application, pour voir rapidement le nombre de fiches trouvées et le total associé.

## Lecture du circuit d une demande

Le Point financier permet de suivre une demande selon différentes étapes, par exemple :

- conformité ;
- approbation ;
- validation achat ;
- trésorerie ;
- décaissements ;
- refus.

Cela aide à savoir si une fiche est encore en traitement, déjà payée ou bloquée.

## Usage recommandé

Utilisez ce module pour :

- identifier les volumes en attente ;
- suivre la concentration des montants sur certains chantiers ;
- préparer des arbitrages ;
- repérer des retards ou goulots d étranglement.

## Export et partage

Le module permet des exports, utiles pour diffuser un état synthétique ou archiver une situation à une date donnée.

## Ce qu il faut éviter

- tirer des conclusions sans appliquer les bons filtres ;
- confondre montant demandé, montant décaissé et montant prévu ;
- oublier que certaines données peuvent être rattachées indirectement au chantier via le déboursé.

## Résultat attendu

Le Point financier doit permettre une lecture rapide, fiable et actionnable du pipeline des fiches de décaissement.
