# Guide utilisateur

## Qui utilise ce module

Le module Administration systeme est reserve aux administrateurs. Un employe standard n a normalement pas vocation a y travailler.

## Ce qu il permet

Pour un profil autorise, ce module sert a :

- gerer les comptes ;
- ajuster les droits ;
- consulter les journaux ;
- suivre les emails systeme ;
- verifier certains outils techniques.

## Si vous voyez ce module

Si vous avez acces a ce module, utilisez-le avec prudence. Une mauvaise manipulation peut impacter plusieurs utilisateurs ou plusieurs modules.

## En resume

Ce module n est pas un espace metier standard. C est un espace de supervision et de maintenance.
