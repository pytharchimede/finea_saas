# Guide gestionnaire

## Objectif de l Administration systeme

Le module Administration systeme centralise les outils de pilotage, de controle et de parametrage transverse de l ERP.

## Ce que couvre ce module

- gestion des utilisateurs ;
- gestion des acces ;
- audit ERP ;
- outils base de donnees ;
- logs d emails systeme ;
- parametrage des modules portail ;
- maintenance technique ;
- parametres de notifications.

## Pour qui

Ce module s adresse aux profils administration ou support avance. Il ne doit pas etre utilise comme un module metier courant.

## A quoi il sert au quotidien

- creer ou ajuster des comptes ;
- verifier des droits ;
- analyser des anomalies ;
- consulter des journaux ;
- ajuster la presentation du portail ;
- lancer ou verifier certains outils de maintenance.

## Vigilance

Les actions admin peuvent avoir un impact global. Il faut donc :

- limiter les acces ;
- tracer les operations ;
- verifier avant modification ;
- eviter les changements non documentes.

## Resultat attendu

L Administration systeme doit fournir un point de controle central, clair et reserve aux profils de confiance.
