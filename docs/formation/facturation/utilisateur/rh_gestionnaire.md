# Guide gestionnaire

## Objectif du module Facturation

Le module Facturation sert a preparer, verifier et suivre les factures d achat et de vente dans l application, avec prise en compte des contraintes FNE.

## Ce que permet le module

- suivre les factures d achat ;
- suivre les factures de vente ;
- voir les statuts ;
- controler certaines pieces et donnees ;
- suivre la verification ou la signature FNE selon les cas.

## Dashboard Facturation

Le tableau de bord remonte une vision d ensemble sur :

- les volumes de factures ;
- les statuts ;
- les montants ;
- la configuration FNE ;
- les dernieres creations ;
- les alertes de verification.

## Factures d achat

Les factures d achat passent en general par un cycle du type :

- brouillon ;
- a verifier ;
- verifiee ;
- rejetee ;
- payee.

## Factures de vente

Les factures de vente suivent un cycle distinct, plus oriente emission et signature :

- brouillon ;
- a signer ;
- signee ;
- erreur.

## Role d un gestionnaire

Un gestionnaire doit surtout verifier :

- la completude des donnees ;
- la disponibilite des pieces ;
- la coherence des statuts ;
- les dependances fournisseur / client / FNE.

## Resultat attendu

Le module doit fiabiliser la chaine de facturation et donner une vision claire des dossiers en cours.
