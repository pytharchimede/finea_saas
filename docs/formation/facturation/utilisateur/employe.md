# Guide utilisateur

## A quoi sert ce module

Le module Facturation permet de consulter et traiter les factures selon vos droits.

## Ce que vous pouvez y faire

- consulter le tableau de bord ;
- ouvrir les factures d achat ;
- ouvrir les factures de vente ;
- verifier un statut ;
- completer ou corriger une facture selon vos habilitations.

## Ce qu il faut verifier sur une facture d achat

- le fournisseur ;
- le numero de facture ;
- la piece jointe ;
- les lignes ;
- la devise ;
- le statut de verification.

## Ce qu il faut verifier sur une facture de vente

- le client ;
- les lignes ;
- le total ;
- le statut de signature ;
- la presence d une erreur eventuelle.

## En resume

Le module Facturation sert a suivre l avancement des factures et a fiabiliser les informations avant les traitements definitifs.
