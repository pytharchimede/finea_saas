# Guide employe

## A quoi sert Mes tâches

Mes tâches sert à recevoir, suivre et terminer les actions qui vous sont confiées dans l application.

Au lieu de chercher les informations dans plusieurs messages, vous retrouvez au même endroit :

- la tâche à faire ;
- la date limite ;
- les commentaires ;
- les documents joints ;
- l état d avancement.

## Ce que vous devez faire quand une tâche vous est attribuée

1. ouvrir le module Mes tâches ;
2. lire le titre et la description ;
3. vérifier la date d échéance ;
4. commencer le travail demandé ;
5. ajouter un commentaire si vous avez une question ou un retour ;
6. joindre un document si nécessaire ;
7. mettre à jour le statut quand le travail avance ou se termine.

## Lire une tâche correctement

Avant d agir, vérifiez toujours :

- ce qui est demandé exactement ;
- pour quand c est demandé ;
- s il y a un document joint ;
- qui a créé la tâche ;
- s il existe déjà des commentaires utiles.

Si quelque chose n est pas clair, répondez dans les commentaires de la tâche.

## Ajouter un commentaire

Le commentaire sert à :

- poser une question ;
- confirmer que vous avez commencé ;
- signaler un blocage ;
- indiquer que le travail est terminé ;
- préciser où en est le dossier.

Bon réflexe : laissez une trace écrite dans la tâche au lieu de faire uniquement un retour verbal.

## Ajouter une pièce jointe

Ajoutez une pièce jointe quand vous devez fournir :

- un document ;
- une capture ;
- une photo ;
- une preuve de réalisation ;
- un fichier de travail.

Avant d envoyer un fichier :

- vérifiez que c est le bon document ;
- donnez un nom clair au fichier si possible ;
- évitez les doublons inutiles.

## Mettre à jour le statut

Le statut permet de montrer où vous en êtes.

Exemples simples :

- en attente : vous n avez pas encore commencé ;
- en cours : vous travaillez dessus ;
- terminée : l action est finie ;
- annulée : la tâche ne doit plus être exécutée.

Changez le statut dès que la situation évolue. Cela évite les relances inutiles.

## Lien avec votre planning

Certaines tâches peuvent aussi être prises en compte dans l emploi du temps.

Cela signifie que la tâche peut être positionnée dans un créneau de travail. Si vous voyez la tâche dans votre planning, cela ne change pas ce que vous devez faire :

- lire ;
- exécuter ;
- commenter ;
- clôturer.

## Si vous êtes bloqué

Si vous ne pouvez pas avancer :

1. ouvrez la tâche ;
2. ajoutez un commentaire clair ;
3. expliquez le blocage ;
4. précisez ce qu il manque pour continuer.

Exemples de blocage :

- document manquant ;
- validation en attente ;
- information incomplète ;
- accès non disponible.

## Bonnes habitudes

- consultez régulièrement Mes tâches ;
- répondez directement dans la tâche ;
- joignez les preuves utiles ;
- mettez le bon statut ;
- ne laissez pas une tâche terminée en cours.

## Ce qu il faut éviter

- ignorer une tâche sans retour ;
- répondre par téléphone seulement ;
- créer une nouvelle tâche pour parler d une tâche existante ;
- envoyer la preuve ailleurs si elle doit être attachée à la tâche.

## En resume

Si vous utilisez bien Mes tâches, votre travail est plus simple à suivre, plus clair pour votre responsable et mieux tracé dans l application.
