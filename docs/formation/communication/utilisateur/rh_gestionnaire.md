# Guide RH gestionnaire

## Objectif

Ce module permet de suivre les tâches confiées aux collaborateurs, de voir les échéances et de garder un historique simple des échanges autour de chaque tâche.

Pour un responsable RH ou un gestionnaire du planning, l intérêt principal est double :

- voir rapidement qui a quoi à faire ;
- vérifier si une tâche a bien été prise en charge, commentée ou terminée.

## Quand utiliser Mes tâches

Utilisez ce module quand vous devez :

- attribuer une action à un collaborateur ;
- suivre une échéance ;
- demander une mise à jour sur un dossier ;
- centraliser les commentaires et pièces jointes liés à une action ;
- retrouver l historique d une demande sans passer par WhatsApp ou des appels.

## Ce que vous voyez dans le module

Selon votre accès, vous pouvez trouver plusieurs écrans :

- un tableau de bord avec les compteurs et les priorités ;
- une liste de tâches ;
- un espace de commentaires par tâche ;
- un espace de pièces jointes ;
- un espace personnel Mes tâches.

## Créer une tâche

Pour créer une tâche :

1. ouvrez Mes tâches ;
2. cliquez sur le bouton de création ;
3. saisissez un titre clair ;
4. ajoutez une description courte mais précise ;
5. choisissez le collaborateur concerné ;
6. fixez une date d échéance si nécessaire ;
7. enregistrez.

Bonnes pratiques :

- un titre doit être simple et actionnable ;
- une tâche doit correspondre à un seul objectif principal ;
- si plusieurs personnes sont concernées, créez plusieurs tâches séparées ;
- si un document doit être utilisé, joignez-le directement à la tâche.

## Suivre l avancement

Le suivi se fait surtout par :

- le statut de la tâche ;
- les commentaires ;
- les fichiers joints ;
- la date d échéance ;
- la date de réalisation.

Un responsable RH peut donc vérifier :

- si la tâche est encore en attente ;
- si elle est en cours ;
- si elle est terminée ;
- si elle a été annulée ;
- si le collaborateur a ajouté un retour ou une preuve.

## Lien avec l emploi du temps

Certaines tâches peuvent être liées automatiquement au planning du collaborateur.

Concrètement, cela veut dire que :

- une tâche peut apparaître comme un élément planifié ;
- le système essaie de positionner la tâche dans un créneau disponible ;
- la qualité de ce placement dépend du rattachement correct entre l utilisateur et le personnel concerné.

Pour la RH, cela aide à vérifier qu une charge de travail annoncée existe bien dans le planning.

## Comment relancer proprement un collaborateur

Au lieu de recréer une nouvelle tâche, il est préférable de :

1. ouvrir la tâche existante ;
2. ajouter un commentaire de relance ;
3. ajuster la date d échéance si besoin ;
4. demander une pièce jointe ou une confirmation.

Cela garde tout l historique au même endroit.

## Cas pratiques

### Exemple 1 : suivi d un dossier RH

- créer une tâche pour demander un document au salarié ;
- mettre une échéance ;
- ajouter en commentaire la précision attendue ;
- vérifier ensuite si le document a été joint.

### Exemple 2 : action de planning

- créer une tâche pour une mission ou une préparation ;
- contrôler si elle est visible dans l emploi du temps ;
- suivre la clôture via le statut et les commentaires.

## Erreurs à éviter

- créer plusieurs tâches identiques pour la même demande ;
- mettre un titre trop vague ;
- relancer par oral sans laisser de trace dans la tâche ;
- stocker les fichiers ailleurs alors qu ils peuvent être joints à la tâche.

## Résultat attendu

Si le module est bien utilisé, vous obtenez :

- un suivi plus propre des actions ;
- moins de pertes d information ;
- un meilleur contrôle des échéances ;
- une trace claire de ce qui a été demandé, fait ou bloqué.
