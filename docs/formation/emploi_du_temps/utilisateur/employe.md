# Guide employe

## A quoi sert Emploi du temps

Le module Emploi du temps vous permet de voir vos activités planifiées dans l application.

Vous pouvez y retrouver :

- vos créneaux personnels ;
- certaines tâches liées au planning ;
- l état d avancement de vos activités ;
- vos rappels ou actions complémentaires.

## Ce que vous pouvez faire

Selon vos droits, vous pouvez :

- consulter votre planning ;
- créer un créneau ;
- modifier un créneau ;
- changer le statut d une activité ;
- exporter votre planning ;
- consulter la liste des tâches associées.

## Lire votre planning

Quand vous ouvrez le module, prenez l habitude de vérifier :

- la période affichée ;
- vos créneaux du jour ou de la semaine ;
- les activités déjà terminées ;
- les activités encore planifiées ;
- les éventuels conflits ou oublis.

## Ajouter un créneau

Pour créer un créneau :

1. ouvrez votre emploi du temps ;
2. cliquez sur la plage horaire souhaitée ;
3. indiquez un titre clair ;
4. renseignez le début et la fin ;
5. choisissez le statut ;
6. ajoutez une description si nécessaire ;
7. enregistrez.

Exemples de titres utiles :

- Réunion chantier ;
- Préparation dossier ;
- Déplacement client ;
- Traitement tâche RH.

## Modifier ou déplacer un créneau

Vous pouvez ajuster un créneau si :

- l horaire a changé ;
- le lieu a changé ;
- l activité a été décalée ;
- le statut n est plus correct.

Le système empêche normalement les chevauchements avec d autres créneaux. Si une mise à jour est refusée, c est souvent parce qu un autre créneau existe déjà sur la même période.

## Comprendre les statuts

Les statuts vous aident a montrer votre progression :

- planifiée : activité prévue ;
- en cours : activité démarrée ;
- en pause : activité temporairement arrêtée ;
- terminée : activité finie ;
- annulée : activité abandonnée.

Pensez a mettre le bon statut, surtout quand une activité est terminée.

## Exporter votre planning

Le module permet d exporter votre planning en fonction de la période choisie.

Cela peut servir pour :

- partager votre semaine ;
- garder une copie ;
- imprimer un aperçu.

## Lien avec vos tâches

Une partie de vos tâches peut apparaître dans l emploi du temps.

Cela ne remplace pas Mes tâches. L idée est plutôt :

- Mes tâches pour suivre ce qui vous est demandé ;
- Emploi du temps pour voir quand cela s insère dans votre organisation.

## Microsoft To Do

Le module peut aussi afficher des éléments venant de Microsoft To Do si votre compte est connecté.

Cela permet de consulter au même endroit :

- vos éléments de planning internes ;
- certaines tâches Microsoft.

Si vous voyez un bouton de connexion Microsoft, utilisez-le seulement si votre service vous a demandé cette synchronisation.

## Bonnes habitudes

- vérifiez votre planning chaque jour ;
- corrigez rapidement les horaires erronés ;
- utilisez des titres courts mais précis ;
- marquez les activités terminées ;
- gardez vos tâches et votre planning cohérents.

## En résumé

Le module Emploi du temps vous aide à organiser vos journées, à suivre vos activités prévues et à garder une vue claire de votre charge de travail dans l application.
