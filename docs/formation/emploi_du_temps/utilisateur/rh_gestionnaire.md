# Guide RH gestionnaire

## Objectif du module

Le module Emploi du temps sert a organiser les créneaux de travail, visualiser la charge planifiée et suivre les actions inscrites dans le calendrier d un collaborateur.

Pour la RH ou un responsable de coordination, ce module permet surtout de :

- voir rapidement le planning d un employé ;
- contrôler les créneaux déjà occupés ;
- positionner ou corriger une activité ;
- exporter un planning ;
- vérifier que les horaires de planification sont cohérents.

## Ce que la RH peut faire

Dans l usage quotidien, la RH peut utiliser ce module pour :

- consulter l agenda d un collaborateur ;
- ajouter un créneau manuellement ;
- modifier un créneau existant ;
- changer le statut d une activité ;
- suivre les tâches liées au planning ;
- exporter le planning en CSV ou PDF ;
- renvoyer vers la page RH de paramétrage des horaires.

## Comprendre les vues disponibles

Le module peut afficher le planning selon plusieurs périodes :

- jour ;
- semaine ;
- mois ;
- année.

La vue semaine est généralement la plus utile pour la coordination opérationnelle.

## Créer un créneau dans le planning

Pour ajouter un créneau :

1. ouvrez l emploi du temps ;
2. sélectionnez la bonne personne ;
3. cliquez sur le créneau souhaité ;
4. renseignez le titre ;
5. définissez le début et la fin ;
6. choisissez le statut ;
7. ajoutez si besoin une description ou un lieu ;
8. enregistrez.

Bonnes pratiques :

- utiliser un titre simple et clair ;
- éviter les doublons ;
- ne pas superposer deux activités sur le même créneau ;
- compléter le lieu si l activité se fait hors bureau.

## Modifier un créneau existant

Le module permet de :

- déplacer un créneau ;
- changer les heures ;
- corriger le titre ;
- mettre a jour la description ;
- changer le statut.

Si un chevauchement existe avec un autre créneau, le système peut refuser la modification. Cela évite un planning incohérent.

## Comprendre les statuts

Les statuts servent a suivre l état réel d une activité :

- planifiée ;
- en cours ;
- en pause ;
- terminée ;
- annulée.

Le changement de statut permet de distinguer ce qui est seulement prévu de ce qui est réellement exécuté.

## Horaires de planification

Le module tient compte des fenêtres horaires de travail.

L héritage appliqué est le suivant :

1. réglage propre a l employé ;
2. réglage du service ;
3. réglage par défaut.

Cela veut dire qu un collaborateur peut avoir des horaires différents du reste de son service, tout en gardant une base commune si aucun réglage spécifique n existe.

## Où changer les horaires

Le changement des horaires ne se fait plus directement dans l écran Emploi du temps.

Il faut passer par la page RH dédiée aux horaires de planification. Cette séparation est utile pour :

- éviter les changements accidentels ;
- centraliser le paramétrage RH ;
- distinguer la consultation du planning de l administration des règles horaires.

## Lien avec Mes tâches

Certaines tâches créées dans Mes tâches peuvent remonter dans l emploi du temps.

Pour la RH, cela permet de mieux voir :

- la charge annoncée ;
- les actions attribuées ;
- la cohérence entre tâche et planning.

Si une tâche n apparaît pas, cela peut venir d un problème de rattachement entre l utilisateur et le personnel, ou d une impossibilité de placement horaire.

## Exporter le planning

Le module propose des exports pour partager ou archiver une vue planning.

Cas utiles :

- envoyer un planning hebdomadaire ;
- garder une preuve d organisation ;
- travailler hors application sur une période donnée.

## Conseils d utilisation RH

- toujours vérifier que le bon collaborateur est sélectionné ;
- corriger rapidement les créneaux erronés ;
- garder des titres de créneaux homogènes ;
- utiliser les statuts pour suivre la réalité terrain ;
- vérifier les horaires RH avant de conclure qu un placement automatique est impossible.

## Résultat attendu

Si le module est bien utilisé, la RH obtient un planning plus lisible, une meilleure visibilité sur les disponibilités et un meilleur lien entre organisation du travail et suivi des tâches.
